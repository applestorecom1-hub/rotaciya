# Ротация

Дайджест внутренней мобильности: новые механики переходов между командами и главные новости. Один статичный файл `index.html`, без сборки и зависимостей.

## Как опубликовать на GitHub Pages

1. Создайте на GitHub новый публичный репозиторий, например `rotaciya`.
2. Загрузите в него файлы из этой папки: `index.html`, `README.md`, `.nojekyll`.
   - Через сайт: **Add file → Upload files**, перетащите файлы, нажмите **Commit changes**.
   - Файл `.nojekyll` скрытый. Если не получается его перетащить, можно пропустить: сайт заработает и без него.
3. Откройте **Settings → Pages**.
4. В блоке **Build and deployment** выберите **Source: Deploy from a branch**, ветку `main` и папку `/ (root)`. Нажмите **Save**.
5. Через 1–2 минуты сайт будет доступен по адресу `https://<ваш-логин>.github.io/rotaciya/`.

## Как выпускать новый номер

1. Сохраните текущий выпуск в архив: скопируйте `index.html` в `issues/01.html`.
2. Обновите `index.html`: блоки «Коротко», «Фишки», «Новости» и дату в шапке.
3. В разделе «Выпуски» добавьте новую строку, а у прошлого выпуска поставьте ссылку на `issues/01.html`.
4. Закоммитьте изменения. Сайт обновится сам за минуту-две.

## Структура страницы

- **Коротко** — 4–5 главных мыслей выпуска.
- **Фишки** — новые механики: что это, кто так делает, как попробовать у себя.
- **Новости** — короткая лента с датами и ссылками на источники.
- **Выпуски** — архив.

Шрифты Onest и JetBrains Mono подключаются с Google Fonts. Если они недоступны, страница использует системный шрифт.
